## Using venv
Link with some info:
https://packaging.python.org/en/latest/guides/installing-using-pip-and-virtual-environments/#

Create a virtual environment: 

```bash
python3 -m venv .venv
```

Activate a virtual environment:

```bash
source .venv/bin/activate
```
